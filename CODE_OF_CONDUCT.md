# Code of Conduct

## Purpose

This repository exists to support focused, constructive, and human-led technical work.

The goal of this Code of Conduct is not to police behaviour exhaustively, but to set clear expectations for participation and to give maintainers the authority to keep discussion signal-rich, respectful, and relevant.

---

## Expected Behaviour

Participants are expected to:

- Engage in good faith and with genuine intent.
- Be respectful of differing viewpoints and experiences.
- Focus discussion on the system as implemented, not abstract or speculative concerns.
- Accept that this is a maintained space, not a free-for-all.

Human judgment, context, and intent matter here.

---

## Unacceptable Behaviour

The following are not acceptable in this repository:

- Harassment, intimidation, or personal attacks.
- Disruptive, hostile, or bad-faith participation.
- Drive-by commentary that adds noise without intent to engage.
- Automated, scripted, or unreviewed LLM-generated participation presented as human contribution.
- Engagement primarily intended to boost visibility, reputation, or activity metrics rather than improve the project.

This list is not exhaustive. Maintainers may act on behaviour that undermines the purpose of the repository even if it is not explicitly listed here.

---

## Scope

This Code of Conduct applies to all project spaces, including:

- Issues
- Pull requests
- Discussions
- Comments
- Any other interactions within the repository

---

## Enforcement

Maintainers are responsible for interpreting and enforcing this Code of Conduct.

Actions may include, but are not limited to:

- Removing comments or contributions
- Closing issues or pull requests
- Marking activity as spam
- Restricting or blocking participation

Moderation decisions are made at the maintainers’ discretion. They are not subject to debate, appeal, or proof of intent.

This repository is not a court of law. Participation is a privilege, not a right.

---

## Reporting

If you believe someone is violating this Code of Conduct, you may report it privately to the maintainer.

However, the maintainer may also act without a report when behaviour clearly violates the spirit or letter of this document.

---

## Final Note

This project values clarity, intent, and respect over volume or activity.

If you are unsure whether something belongs here, err on the side of asking first.
