    The check nothing can do for you

    Bubbles speaks a line through the whole path, and the virtual microphone the stream reads is measured while it does. Note that you will not hear Bubbles on this machine unless monitoring is on — its voice goes straight to the stream — so the measured level, not your ears, is what tells you it worked.

    Talk into each microphone in turn and watch which meter moves — that is how you tell which channel is whose. The name you set here is the name that appears in the transcript.
